# Security reporting

Report security concerns privately to [contact@katge.com](mailto:contact@katge.com).
Include the affected version, reproduction steps and impact in a redacted initial
description. Arrange a private channel before sharing sensitive evidence.

Do not publish credentials, signed URLs, private content, internal configuration
or raw logs in issues. This repository contains product documentation and public
contracts; it does not contain the private processing implementation.

The backend-connected client requires the Katge service. Source observations do
not grant authority; authentication, tenant, scope and source validation remain
service responsibilities. Development builds do not certify a public deployment.
