# The Katge website

[katge.com](https://katge.com) is the product website: the place to understand
Katge, explore its interfaces and follow documentation and release information.

[Overview](../README.md) · [Extensions](extension.md) · [Release status](releases.md)

## Explore the product

The website introduces the source-to-result workflow and the browser experience.
The public documentation connects extensions, REST API and MCP as interfaces to
the same product. It explains what data is shared and distinguishes available
features from development previews.

The development preview below shows Katge's existing visual language and
navigation. It is not a screenshot of a verified production integration.

![Katge development website with its green pixel brand and interface navigation](../assets/product-preview.png)
